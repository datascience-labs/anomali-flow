# AnomaliFlow — Wireframe Documentation

> React + TypeScript + Ant Design 기반 확장 웹앱 UI 와이어프레임

---

## 1. 전체 화면 구성 (Screen Map)

```
AnomaliFlow
│
├── /login                        # 로그인 페이지
├── /register                     # 회원가입 페이지
│
└── / (인증 후)
    ├── /dashboard                # 대시보드 (홈)
    ├── /datasets                 # 데이터셋 관리
    │   ├── /datasets/upload      # CSV 업로드
    │   └── /datasets/:id         # 데이터셋 상세
    ├── /experiments              # 실험 목록
    │   ├── /experiments/new      # 새 실험 생성
    │   └── /experiments/:id      # 실험 결과 상세
    └── /settings                 # 설정 (프로필, 워크스페이스)
```

## 16. 컴포넌트 상태 정의 (Component States)

### TaskStatusBadge

| 상태 | 색상 | 아이콘 | 텍스트 |
|------|------|--------|--------|
| PENDING | 회색 | ⏸ | 대기 중 |
| STARTED | 파란색 + 애니메이션 | ⟳ | 실행 중 |
| SUCCESS | 초록색 | ✓ | 완료 |
| FAILURE | 빨간색 | ✗ | 실패 |

### 알고리즘 선택 카드

| 상태 | 시각 표현 |
|------|---------|
| 선택 가능 | 흰 배경, 회색 테두리 |
| 호버 | 파란 테두리, 그림자 |
| 선택됨 | 파란 배경, 체크 표시 |
| 비활성 (데이터 유형 불일치) | 회색, 비활성화 처리 |
